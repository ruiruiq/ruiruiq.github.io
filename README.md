# Guorui Xu — Academic Homepage

Personal academic homepage at **https://ruiruiq.github.io/**, hosted with GitHub Pages.

The page uses a compact, single-column academic layout with a profile header, research introduction, bibliography-style publications, and education and experience.

## Edit the website

- `index.html`: biography, selected publications, and experience.
- `assets/site.css`: layout, typography, responsive styles, and colors.
- `assets/favicon.svg`: site icon.
- `assets/shushu-cat.jpg`: the Shushu cat (Swag Cat) profile avatar.
- `papers/`: the final PDF of each featured paper.

The site uses static HTML, CSS, and a small JavaScript integration for the visitor map. No package installation or build step is required. GitHub Pages publishes from the root of the `master` branch; `.nojekyll` keeps the site static.

To preview locally, serve this directory with any static web server, such as `python -m http.server 4173`, then open `http://localhost:4173`.

Biography dates and institution names were supplied by Guorui Xu. Publication entries use verified author lists. Academic degree names and job titles are omitted until supplied. Both final PDFs designate Guorui Xu and Xiang Liu as equal contributors.

PDFs are the author's unmodified final versions and retain their embedded copyright and license notices. EXPCheck's fourth author is listed as Qiang Su in the conference program (the PDF spells the name Qing Su); the web entry follows the official program.

The original Hugo starter files and Git history remain available. The homepage is maintained directly in `index.html`.

## Visitor map

The [public visitor map](https://whos.amung.us/stats/maps/w5mpt36rh37h/) is hosted by whos.amung.us. Its free widget displays current and some recent visits using approximate IP-based locations. People on the same network can share a pin. A VPN can place the pin near its exit server. The public widget ID is `w5mpt36rh37h`. [Provider documentation](https://whos.amung.us/help/)

The homepage shows a local [Natural Earth land map](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/) from the [public domain](https://www.naturalearthdata.com/about/terms-of-use/). Clicking the map loads the live widget for that visit. Clicking again opens the public visitor map, including when the widget is unavailable. With JavaScript disabled, the map links directly to the public statistics. [Provider privacy policy](https://whos.amung.us/legal/privacy/)
